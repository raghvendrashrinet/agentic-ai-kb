
### Install Ollama docker Image
```
docker run -d -v ollama:/root/.ollama -p 11434:11434 --name ollama ollama/ollama
```

### OpenWebUI
`OpenWebUI` is a browser-based interface for running and interacting with LLMs  
It’s designed to work with local backends like Ollama, so you can run models on your own machine and access them through a clean web interface.
 - Ollama Backend: runs locally (ollama serve) and exposes an API at `http://localhost:11434`.
 - It manages your models (`ollama pull llama3.1`, `ollama run llama3.2:1b`, etc.).  

  `OpenWebUI Frontend`: `http://localhost:3000`
  - OpenWebUI connects to Ollama’s API.
  - In OpenWebUI settings, you configure the base URL for Ollama (default: `http://localhost:11434`).
  - ou select which model to use (`llama3.1:latest, llama3.2:1b`, etc.).

```
# 1. Start Ollama server, If you install no docker then ollama service need to be started
# For docker ollama is already running
ollama serve

# 2. Run a model (optional, OpenWebUI can trigger it too)
ollama run llama3.1:latest

# 3. Start OpenWebUI (depends on install method, e.g. Docker)
docker run -d -p 3000:3000 --name openwebui ghcr.io/open-webui/open-webui:main

# 4. Open browser
http://localhost:3000

```
In OpenWebUI settings:
```
Set LLM_BASE_URL=http://localhost:11434

Choose your model (llama3.1:latest, llama3.2:1b, etc.)
```
