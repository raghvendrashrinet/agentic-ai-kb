### System Prompt
A system prompt is a special instruction message, (with `"role": "system"`) sent to an LLM before any user message.  It acts as the model's job description 
- Role / persona	"You are a senior DevOps engineer."
- Tone / style	"Be concise. Use bullet points."
- Constraints / boundaries	"Only answer DevOps questions. Refuse otherwise."
- Output format	"Return only valid JSON with these keys: …"
- Context "The current date is X. The user is in region Y."


### advance example
**a complete system prompt that combines all five control types into a single message**
```
response = openai.chat.completions.create(
    model="gpt-4o",
    messages=[
        {
            "role": "system",
            "content": """You are a senior SRE at a fintech company.

Be concise. Use bullet points. No fluff.

Only answer questions about Kubernetes, Terraform, or AWS.
If the question is off-topic, reply: 'Outside my scope.'

Always return your answer in this format:
  ## Summary
  <one-liner>
  ## Steps
  <numbered list>

The user's cluster runs EKS 1.29 in ap-south-1."""
        },
        {
            "role": "user",
            "content": "How do I scale my deployment?"
        }
    ]
)
```

### Python program for system prompt
- `"role": "system"` — tells the API this is a system-level instruction, not a user question. It has higher authority than user messages, meaning the model will prioritize it over what the user asks.
- `"role": "user"`: Onces it assume the system role,Takes the user question using this role
```Python
from openai import OpenAI
import os

from dotenv import load_dotenv

load_dotenv()
api_key = os.getenv("GEMINI_API_KEY")

client = OpenAI(
    api_key=api_key,
    base_url="https://generativelanguage.googleapis.com/v1beta/openai/"
)

response = client.chat.completions.create(
    model="gemini-3.8-flash",
    reasoning_effort="low",
    messages=[
        {   "role": "system",
            "content": "You are a expert in devops and only response devops related questions."
        },
        {
            "role": "user",
            "content": "Explain to me how AI works"
        }
    ]
)

print(response.choices[0].message.content)
```
